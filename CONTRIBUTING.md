# Contributing

Thank you for helping build Tremelay.

Before contributing, read `AGENTS.md`, `SECURITY_INVARIANTS.md`, and `THREAT_MODEL.md`.

Substantive security-boundary changes should be proposed with an ADR under `docs/adr/`.

Pull requests should include:
- problem and intended behavior
- security impact
- tests added/changed
- relevant threat-model considerations
- migration or compatibility impact where applicable
